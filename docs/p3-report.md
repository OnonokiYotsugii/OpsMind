## Architecture

LLM → 工具调用 → 白名单和校验 → 只读执行或等待确认 →
Tool Result → LLM。下一步由模型选择，权限、预算、事务与审批由程序决定。

新增 agent_run 表存储状态、消息、事件和待确认动作。
模型网络请求在数据库事务之外；审批持有行锁，
业务保存与执行凭据在同一个事务中，失败使用保存点回滚业务修改。
