# ADR 0002：P1 同步后端、MySQL 测试与本地演示身份

状态：接受。日期：2026-09-12。

## 决策

FastAPI 同步路由调用同步 SQLAlchemy / PyMySQL，数据库事务由服务层负责，Session 按请求创建和关闭。工单更新先锁行再检查状态；不自动重试写请求，避免重复创建。

Alembic 迁移显式定义表结构，不导入后续可能变化的 ORM 类生成旧迁移。数据库时间由应用写入 UTC，MySQL 使用 DATETIME(6)，API 输出 UTC 时区。

P1 不实现登录系统；默认本机运行，由环境配置固定演示操作员工。生产环境拒绝启动；未来加入认证时替换 API 身份依赖，不让业务服务信任用户传入的 created_by。

数据库分别使用应用账号、迁移账号、测试账号。应用账号没有 DELETE 或建表权限。真实测试限定本机 opsmind_test，每个测试通过事务回滚数据变更。

## 取舍

同步代码易于初学者理解和调试，未来是否改为异步由测量决定。固定身份不能证明真实用户是谁，所以只能本地演示，不宣称是完整权限系统。

数据库约束测试发现 MySQL 3819 被 PyMySQL 映射为 OperationalError；错误处理按实际码区分数据冲突和连接故障。保留具体错误码断言，避免宽泛捕获让测试虚假通过。

选择 FastAPI TestClient + httpx 沿用 P1 计划；锁定版本目前产生两条上游弃用警告，后续客户端迁移单独处理。
