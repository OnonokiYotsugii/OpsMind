# GitHub 与面试展示准备

## 仓库首页

README 已包含界面截图、架构图、启动入口、验证结果与限制。提交时保留源代码、测试、迁移、知识库虚构资料和文档。`.env`、`.data`、`.cache`、`.venv` 不进入 Git。当前尚未执行 Git 提交、创建远程仓库或推送。

先运行 `git status --short`，核对改动。P5–P7 仍可能一起处于未提交状态，应在确认文件后按实际开发内容组织提交。不要把自动测试通过写成真实模型准确率。

## 项目讲解提纲

- 业务问题：设备故障信息分散，人工需要查历史、找资料、填写工单。
- 实现：FastAPI + MySQL 业务服务，工具白名单，LangGraph 状态和恢复，本地 RAG。
- 关键设计：参数验证、模型输出与执行分离、人工确认、原子执行凭据防重复写入。
- 验证：真实 MySQL 集成测试、受控模型回归、独立的真实模型评测模式。
- 局限：本机演示身份、小型评测集、尚未完成容器实跑与最终真实模型联调。
