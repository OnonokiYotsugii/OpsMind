# Markdown 显示改进（2026-10-12）

回答区域支持多级标题、加粗、列表、引用、表格、代码块和 HTTP(S) 链接。由本地 Marked 解析，再由 DOMPurify 白名单过滤为 DOM 片段后插入，审批参数保持纯文本。来源编号保持原文，不改变服务端引用验证。

两个浏览器库固定版本并附许可证及完整性记录，见 src/opsmind/web/vendor/README.md。禁止脚本、事件属性、外部图片、表单、SVG、样式和危险链接。依赖加载失败则回退纯文本。后续需跟进过滤库安全更新。

验证：Chrome 浏览器覆盖实际查询结果渲染、标题/列表/表格/代码、引用编号、390px 布局、六组恶意输入、外部请求拦截、库失效回退；测试均通过。静态资源 API 测试通过，没有调用付费模型。

使用：浏览器 Ctrl+F5 强制刷新；用已有运行编号点击“查询”即可重新排版历史结果，不需要重新发起任务或消耗模型额度。
